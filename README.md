# Caesar Cipher Encryptor
A simple encryption and decryption application developed in C using the Caesar Cipher algorithm. The program allows users to encrypt messages, store them in a text file, and decrypt them back to their original form.


## How It Works

### Encryption
1. Select the **Encrypt** option.
2. Enter a message.
3. Each character is shifted by a fixed value of 5.
4. The encrypted message is displayed and saved to `EncryptedText.txt`.

### Decryption
1. Select the **Decrypt** option.
2. The program reads the encrypted message from `EncryptedText.txt`.
3. Each character is shifted back by the same value.
4. The original message is displayed.
